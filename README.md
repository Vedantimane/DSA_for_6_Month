# DSA Study Plan

## **Goal:** Build a solid foundation in Data Structures and Algorithms (DSA) in Java.

---

## **Month 1: Core Java Basics**

- **Focus:** Java Syntax, OOP principles.
- **Daily:**
  - **30 mins:** Variables, loops, conditionals, arrays, strings.
  - **40 mins:** OOP (Classes, inheritance, polymorphism).
  - **50 mins:** Java Collections (ArrayList, HashMap, HashSet).

---

## **Month 2: Big O Notation and Basic Data Structures**

- **Focus:** Time complexity, Arrays, Strings, Linked Lists.
- **Daily:**
  - **30 mins:** Big O notation, analyzing complexities.
  - **40 mins:** Arrays/Strings (rotation, merging, searching).
  - **50 mins:** Linked Lists (insertion, deletion, reversal).

---

## **Month 3: Stack, Queue, and Recursion**

- **Focus:** Stacks, Queues, Recursion applications.
- **Daily:**
  - **30 mins:** Stack (push/pop, balanced parentheses).
  - **40 mins:** Queue (BFS, circular queue).
  - **50 mins:** Recursion (Fibonacci, N-Queens).

---

## **Month 4: Trees and Graphs**

- **Focus:** Binary trees, Graph algorithms.
- **Daily:**
  - **30 mins:** Binary Trees (in-order, pre-order, post-order).
  - **40 mins:** Graphs (BFS, DFS, cycle detection).
  - **50 mins:** Solve tree/graph problems (LCA, shortest path).

---

## **Month 5: Sorting, Searching, and Dynamic Programming (DP)**

- **Focus:** Sorting algorithms, Binary Search, DP.
- **Daily:**
  - **30 mins:** Sorting (Bubble, Merge, Quick Sort).
  - **40 mins:** Binary Search (search in rotated array).
  - **50 mins:** DP (Fibonacci, knapsack).

---

## **Month 6: Advanced Topics**

- **Focus:** Advanced data structures, graph algorithms, Greedy algorithms.
- **Daily:**
  - **30 mins:** Advanced Data Structures (Segment Tree, Tries).
  - **40 mins:** Advanced Graph Algorithms (Dijkstra’s, Floyd-Warshall).
  - **50 mins:** Greedy Algorithms (activity selection, Huffman encoding).

---

## **Problem-Solving and Competitive Programming**

- **Daily Practice:** Solve 1–2 problems on platforms like LeetCode, HackerRank.
- **Weekly:** Review topics and focus on weak areas.

---
